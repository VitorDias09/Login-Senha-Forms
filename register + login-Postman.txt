====================================================================
GUIA COMPLETO DE TESTES NO POSTMAN - API FLASK REST COM AUTENTICAÇÃO JWT
====================================================================

Como configurar o Token JWT no Postman:
1. Realize a requisição de Login (item 2).
2. Copie o valor do "access_token" retornado no corpo da resposta.
3. Nas rotas protegidas:
   - Vá na aba "Authorization" da requisição.
   - Em "Type", selecione "Bearer Token".
   - No campo "Token", cole o token copiado.

Base URL: http://127.0.0.1:5000

====================================================================
1. FLUXO BÁSICO: CADASTRO E LOGIN
====================================================================

[POST] 1.1 Cadastrar Novo Usuário
URL: http://127.0.0.1:5000/users/register
Headers:
  Content-Type: application/json
Body (raw - JSON):
{
  "username": "aluno_teste",
  "password": "senha123"
}
Resposta esperada (201 Created):
{
  "message": "Usuário registrado com sucesso"
}

--------------------------------------------------------------------

[POST] 1.2 Login de Usuário (Gerar Token JWT)
URL: http://127.0.0.1:5000/users/login
Headers:
  Content-Type: application/json
Body (raw - JSON):
{
  "username": "aluno_teste",
  "password": "senha123"
}
Resposta esperada (200 OK):
{
  "access_token": "eyJhbGciOiJIUzI1NiIsIn..."
}
* COPIE O TOKEN GERADO PARA USAR NAS ROTAS ABAIXO *
